Editing happens in this browser only

Every change is written to this browser's local storage. There is no server behind this page, so an edit here does not reach a visitor on another phone or laptop, and there is no password because there is nothing to protect yet — anyone who opens this file can type in it.

What is live: the moment you save, the guide and the landing page already open in other tabs of this browser re-render with your change. To put a listing in front of visitors, use Export below and paste the result into data/stores.js — or host the site, and this panel can write to a real database instead.

Export the working set

This is the whole listing set as it stands in this browser. Two ways to publish it:

  1. Keep the file. Save it next to data/stores.js and replace that file's MARKET_DATA object with this content, keeping the window.MARKET_DATA = …; wrapper at the top of the file.
  2. Photographs. Any photo you added is inside this text as a data URL, which is why the file gets big. For a hosted site, save each picture into assets/img/ and put its path in the photo field instead.
